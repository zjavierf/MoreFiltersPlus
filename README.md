## Features

### Filters
- Not FC'd
- Vivify
- Chroma
- Noodle Extensions
- Mapping Extensions
- Standard, One Saber, No Arrows, 90 Degrees, and 360 Degrees

### Sorters
- Mapper Name (with alphabet scrolling legend)
- Mistakes (Tracks misses, bad cuts, and wall hits from local scores)
- Note Count
- Note Density ( Notes Per Second(NPS) )

## Requirements
- [BetterSongList](https://github.com/kinsi55/BeatSaber_BetterSongList)
- [SongCore](https://beatmods.com/mods/58)
- [SongDetailsCache](https://github.com/kinsi55/BeatSaber_SongDetails)

## Installation
1. Download the latest release.
2. Drag and drop the files into your main Beat Saber directory.
